# Checkout analysis exercise

Run checkout.sas in SAS or checkout.sps in SPSS against ExperimentArms.csv. The
data contains two aggregate rows. Weight the contingency table by observation
count. Compare the Pearson chi-square p-value with Experiment.csv. The square of
the uncorrected pooled two-sample proportion z-statistic equals the Pearson
statistic for this 2x2 table. Use the uncorrected Pearson result to compare.
Risk difference sign depends on level order. DataFlow reports treatment minus
control. The source checkout assignment is by synthetic session and the result
is a demo analysis. SAS and SPSS runs require the corresponding software.
